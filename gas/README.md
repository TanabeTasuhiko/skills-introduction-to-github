# 納税アナウンス自動通知システム(Googleスプレッドシート+GAS)

顧問先への納税期限の通知を自動化します。追加費用ゼロ(Googleアカウントのみ)で動きます。

## 管理する4項目

| 項目 | 期限の決まり方 | データの持ち方 |
|---|---|---|
| ① 源泉所得税 | 納期特例:7/10・1/20/毎月納付:翌月10日 | **顧客マスタから自動計算**(入力不要) |
| ② 本決算 | 決算月末の2ヶ月後(延長法人は3ヶ月後) | **顧客マスタから自動計算**(入力不要) |
| ③ 予定納税・中間申告 | 法人ごとにバラバラ | **「予定納税一覧」シートが正本**。決算月から期限行を自動生成し、金額だけ手入力 |
| ④ 事前確定届出給与 | 届出書に記載した支給日 | 「事前確定給与」シートに届出内容を転記 |

期限が土日・日本の祝日の場合は自動で翌営業日に繰り下げて通知します。

## 通知の動き

- 毎朝7時台に自動チェックし、**期限の30日前・7日前・前日**に顧問先へメール送信(タイミングは設定シートで変更可)
- 本決算のみ **60日前**にも「決算資料のご準備」案内を追加送信
- 源泉の毎月納付は7日前以内のみ(毎月30日前通知はうるさいため)
- 事前確定給与の通知には「**1日・1円でもズレると全額損金不算入**」の警告文を自動で入れます
- 同じ通知は二度送りません(通知ログで重複防止)。送信結果は毎日管理者にサマリーメールが届きます
- **テストモード**では全メールが管理者にだけ届くので、安全に試せます

## セットアップ手順(約15分)

### 1. スプレッドシートとスクリプトの準備

1. Googleスプレッドシートを新規作成し、名前を「納税通知システム」などにする
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付けて保存(💾)
4. スプレッドシートに戻り、**再読み込み**(F5)→ メニューに「📮 納税通知」が現れる

### 2. 初期化とデータ入力

5. **📮 納税通知 → ① 初期セットアップ** を実行(初回はGoogleの権限承認画面が出るので許可する)
6. **顧客マスタ**に顧問先を入力(下記シート仕様を参照。サンプル行は削除してよい)
7. **📮 納税通知 → ② 予定納税一覧を自動生成** を実行 → 「予定納税一覧」に期限行ができるので、前期申告書を見ながら**金額を入力**する。中間が不要な行(前期税額が基準未満・減額申請など)はステータスを「対象外」に変える
8. **事前確定給与**シートに、提出済みの届出書から支給日・支給額を転記する

### 3. テストと本番稼働

9. 「設定」シートで**管理者メール**を確認し、送信モードが「テスト」のまま **④ 今すぐチェック実行** → 管理者宛に届くメールを確認
10. **③ 今後60日の期限プレビュー** で期限の拾い漏れがないか確認
11. **⑤ 毎朝7時の自動実行を設定** を実行
12. 問題なければ「設定」シートの送信モードを **本番** に変更 → 稼働開始

## シート仕様

### 顧客マスタ(正本:すべての通知がここを参照)

| 列 | 入力内容 |
|---|---|
| 顧客ID | 一意のID(C001など)。予定納税一覧・事前確定給与との紐付けに使う |
| 会社名 | 表示名 |
| 種別(法人/個人) | 個人は予定納税(7/31・11/30)の自動生成に使う |
| 決算月(1-12) | 月末決算前提。本決算・中間期限の計算に使う |
| 申告期限延長(あり/なし) | ありの場合、本決算の期限を3ヶ月後で計算 |
| 源泉所得税(納期特例/毎月/対象外) | 通知パターンの選択 |
| 中間・予定納税(あり/なし) | ありの顧問先だけ②の自動生成対象になる |
| 消費税中間回数(0/1/3/11) | 前期の確定消費税額に応じて入力。11回は自動生成対象外(手動登録) |
| 通知先メール | 未入力の場合は送信されず、管理者サマリーに警告が出る |
| 有効(有効/停止) | 解約した顧問先は「停止」にする(行削除不要) |

### 予定納税一覧(③の正本)

| 列 | 入力内容 |
|---|---|
| 税目 | 自動生成:法人税・地方税 中間/消費税 中間/所得税 予定納税 |
| 期限日 | 自動生成(営業日調整済み)。税務署からの通知と異なる場合は手で直す |
| 金額 | **手入力**(前期申告書・税務署からの通知を参照) |
| ステータス | 未納付=通知対象/納付済・対象外=通知停止 |

**運用ルール:申告書を提出したら、その場で②を実行して翌期の行を生成し金額を入れる。** これを申告完了チェックリストに入れると漏れません。

### 事前確定給与(④の正本)

届出書1件につき1行。支給日・支給額・対象者を届出書のとおりに転記。支給を確認したらステータスを「支給済」に変更。

### 設定

| キー | 説明 |
|---|---|
| 送信モード | テスト=管理者にのみ送信/本番=顧客に送信 |
| 通知タイミング(日前) | 既定 30,7,1。カンマ区切りで変更可 |
| 決算の事前通知日数 | 既定 60。本決算の資料準備案内 |
| CCメール | 全通知を事務所内にCCしたい場合に入力 |

## 制約・注意事項

- **月末決算を前提**に期限を計算しています(月中決算の顧問先は予定納税一覧・本決算とも手動調整)
- 消費税の**年11回中間**は特則があるため自動生成しません(該当先は一覧へ手動登録)
- 中間申告の要否(前期税額の基準)は判定しません。②で生成した行のうち不要なものは「対象外」にしてください
- メール送信上限:無料Gmailは**100通/日**、Google Workspaceは**1,500通/日**(顧問先100件×同日通知でも通常は数十通/日に収まります)
- 通知先の追加(LINE公式アカウント等)は次段階の拡張ポイントです。イベント収集(`collectEvents`)と送信(`sendNotification`)を分離してあるので、送信部分の差し替えだけで対応できます
